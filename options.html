還沒有 API key？ 免費申請步驟：
1. 前往 Google AI Studio → API keys（用 Google 帳號登入）
2. 點 Create API key，複製產生的金鑰
3. 貼到上面欄位，按「儲存」→「測試連線」
金鑰會儲存在本機瀏覽器 (chrome.storage.local)，只在呼叫 Gemini API 時傳送給 Google 驗證。
翻譯內容也會傳送給 Google；請勿在含敏感資料的頁面使用。
